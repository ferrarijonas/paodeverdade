# Pão de Verdade

Site dos cursos presenciais de **Pão** e **Pizza artesanal** — ateliê em Santa Mônica, Uberlândia.

## Páginas

- `index.html` — Home (`/inicio/`)
- `curso-pao.html` — Curso de Pão para Iniciantes
- `curso-pizza.html` — Curso de Pizza Artesanal
- `perguntas.html` — Perguntas Frequentes
- `quem-somos.html` — Quem Somos

## Estrutura

```
assets/
├── css/style.css     → identidade visual (bege, vinho queimado, Playfair Display)
├── js/main.js        → menu mobile + rodapé
└── img/              → logo, fotos e placeholders
```

## Para editar

- **Textos/preços/WhatsApp**: busque por `R$275`, `R$467` e `5534936186847` nos `.html`.
- **Fotos**: substitua `pao-hero.jpg`, `pao.jpg` e os placeholders SVG em `assets/img/`.
- **Checkout**: os botões de compra apontam para o WhatsApp com mensagem pronta. Para usar o Mercado Pago, troque o `href` do botão primário pelo link do checkout.
